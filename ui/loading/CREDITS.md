# Loading-screen illustrations

19th-century plates, all public domain (Wikimedia Commons licence tag checked for each file). Cropped, library
stamps and plate numbers removed, paper made white so the plates can be multiplied onto the page colour, edges faded,
colours softened slightly, resized to 720 px WebP. Made by Claude Code for the loading screen (web/index.html, style.css).
